# M2-03 — Theme → `:ui`

## Goal
Move the app theme into `:ui` `commonMain` so every platform uses the same colours and typography. Android looks exactly the same, including dynamic colour on Android 12+ and the status-bar icon colour.

## Files
Move (use `git`-free moves: create the new file, delete the old one). **Keep the package `com.yogeshpaliyal.deepr.ui.theme`** so importers don't change:
- `app/src/main/java/com/yogeshpaliyal/deepr/ui/theme/Color.kt` → `ui/src/commonMain/kotlin/com/yogeshpaliyal/deepr/ui/theme/Color.kt` (no Android APIs; move as is)
- `app/src/main/java/com/yogeshpaliyal/deepr/ui/theme/Type.kt` → `ui/src/commonMain/kotlin/com/yogeshpaliyal/deepr/ui/theme/Type.kt` (move as is)
- `app/src/main/java/com/yogeshpaliyal/deepr/ui/theme/Theme.kt` → `ui/src/commonMain/kotlin/com/yogeshpaliyal/deepr/ui/theme/Theme.kt`, with the two Android-only parts behind `expect`/`actual`:
  1. Dynamic colour (lines that use `Build.VERSION.SDK_INT`, `LocalContext`, `dynamicDarkColorScheme`/`dynamicLightColorScheme`). In common: `@Composable internal expect fun platformDynamicColorScheme(darkTheme: Boolean): ColorScheme?`. The `when` branch becomes `colorTheme == "dynamic" && dynamicColor -> platformDynamicColorScheme(useDarkTheme) ?: (if (useDarkTheme) DarkColorScheme else LightColorScheme)`.
     **Careful:** today, when dynamic colour is unavailable (Android < 12), "dynamic" falls through to the `useDarkTheme -> DarkColorScheme / else -> LightColorScheme` branches. The fallback above reproduces exactly that; keep the remaining `when` branches unchanged and in the same order.
     - `ui/src/androidMain/.../theme/Theme.android.kt`: returns the dynamic scheme when `Build.VERSION.SDK_INT >= Build.VERSION_CODES.S`, else `null`.
     - `ui/src/jvmMain/.../theme/Theme.jvm.kt` and `ui/src/iosMain/.../theme/Theme.ios.kt`: return `null`.
  2. Status bar (`LocalView`, `view.isInEditMode`, `SideEffect`, `WindowCompat`). In common: `@Composable internal expect fun PlatformSystemBarsAppearance(darkTheme: Boolean)`, called where that block is today.
     - androidMain: today's exact code.
     - jvm and iOS: empty.
- `ui/build.gradle.kts`: add `androidMain.dependencies { implementation(libs.androidx.core.ktx) }` (needed for `WindowCompat`). Nothing else.
