# M2-08a — AccountViewModel's collaborator interfaces → `:shared`

## Goal
Prepare `AccountViewModel` to move to common code (M2-08b) by moving the **interfaces and small types it depends on** into `:shared` `commonMain`, same packages. The Android implementations stay in `:app`. Android behaviour is unchanged.

## Moves (same packages, `app/src/main/java/com/yogeshpaliyal/deepr/` → `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/`)
| File | Change |
|---|---|
| `util/RequestResult.kt` | verbatim (keeps `@Keep`, see Build) |
| `backup/ImportResult.kt` | verbatim (keeps `@Keep`) |
| `analytics/AnalyticsManager.kt` | verbatim (interface) |
| `analytics/AnalyticsEvents.kt` | verbatim (constants) |
| `sync/SyncRepository.kt` | verbatim (interface) |
| `backup/ExportRepository.kt` | `exportToCsv(uri: Uri? = null)` → `exportToCsv(uri: String? = null)` |
| `backup/ImportRepository.kt` | `importFromCsv(uri: Uri)` → `uri: String`; `importBookmarks(uri: Uri, importer)` → `uri: String` |
| `backup/importer/BookmarkImporter.kt` | `import(uri: Uri)` → `import(uri: String)` |
| NEW `backup/AutoBackupRunner.kt` | `interface AutoBackupRunner { suspend fun doWork() }` |

**The `Uri` ⇄ `String` rule** (the only behavioural surface; keep it exact):
- Callers that had a `Uri` pass `uri.toString()`.
- Implementations in `:app` (`ExportRepositoryImpl`, `ImportRepositoryImpl`, `CsvBookmarkImporter`, `HtmlBookmarkImporter`, `ChromeBookmarkImporter`, `MozillaBookmarkImporter`, and any other `BookmarkImporter`) take `String` and convert back first thing with `val uri = uriString.toUri()` (`androidx.core.net.toUri`, i.e. `Uri.parse`). The rest of each body stays verbatim.
- `null` stays `null`.
- Find every implementation and call site with `codegraph callers exportToCsv`, `codegraph callers importFromCsv`, `codegraph callers importBookmarks`, `codegraph callers import`, plus `grep -rn ": BookmarkImporter" app/src`. Update them all, including `app/src/test/.../backup/importer/BookmarkImporterTest.kt` (it implements the interface).

`AutoBackupWorker` (`app/.../backup/AutoBackupWorker.kt`, stays in `:app`) gets `: AutoBackupRunner` and `override` on its existing `suspend fun doWork()`. Nothing else changes in it.

## Build
- `@Keep` in common code: add `androidx-annotation = { module = "androidx.annotation:annotation", version = "1.9.1" }` to the catalog and `implementation(libs.androidx.annotation)` to `:shared` commonMain. androidx.annotation is multiplatform. If `androidx.annotation.Keep` does NOT resolve in commonMain (check with `:shared:compileKotlinJvm`), remove the dependency and `@Keep` instead, and add equivalent `-keep class` rules for these two classes to `app/proguard-rules.pro`. Log which way you went.

## Out of scope
Don't move `AccountViewModel`, the implementations, `ReviewManager` or `AutoBackupWorker` itself. Don't change Koin wiring except where a constructor signature forces it (it shouldn't).
