## How to convert resources
- `import com.yogeshpaliyal.deepr.R` → remove.
- `stringResource(R.string.foo)` / `stringResource(R.string.foo, a, b)` → `stringResource(Res.string.foo)` / `stringResource(Res.string.foo, a, b)` with imports `org.jetbrains.compose.resources.stringResource`, `com.yogeshpaliyal.deepr.ui.resources.Res` and `com.yogeshpaliyal.deepr.ui.resources.foo` (each accessor is a generated extension; import each one used).
- Non-composable access (`context.getString(R.string.foo)`), if any: use `org.jetbrains.compose.resources.getString(Res.string.foo)` (suspend) only where the call site is already in a coroutine. Otherwise stop and report.
- The format placeholders in Compose resources are already positional (M2-02), so passing args works as before.
- None of these files use `R.drawable` (checked).

## Build changes
