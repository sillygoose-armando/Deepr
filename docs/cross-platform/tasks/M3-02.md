# M3-02 — `desktopApp`: Deepr runs on Windows/macOS/Linux

GitHub issue: #10

## Goal
A new Gradle module `desktopApp` (Compose Desktop, JVM) that starts Koin with `sharedModule` + a desktop module and shows the common UI: `DeeprTheme { DeeprApp(...) }`. Same DB schema as Android (SQLDelight `DeeprDB`, migrations included).

## Part A — module
- `settings.gradle.kts`: `include(":desktopApp")`.
- `desktopApp/build.gradle.kts`: plugins `kotlin("jvm")` (via the catalog's kotlin version; add a `kotlin-jvm` plugin alias if missing), `org.jetbrains.compose` (catalog alias `compose.multiplatform`), `org.jetbrains.kotlin.plugin.compose` (`kotlin.compose`). `kotlin { jvmToolchain(17) }`.
  Dependencies: `implementation(project(":ui"))`, `implementation(project(":shared"))`, `implementation(compose.desktop.currentOs)`, `implementation(libs.sqldelight.sqlite.driver)` (catalog entry added in M3-01), `implementation("org.jetbrains.kotlinx:kotlinx-coroutines-swing:<same version as kotlinx-coroutines-core in the catalog>")` (gives `Dispatchers.Main` on desktop; add a catalog entry), Koin core (BOM). Tests: `testImplementation(kotlin("test"))`, `libs.koin.test`.
  `compose.desktop { application { mainClass = "com.yogeshpaliyal.deepr.desktop.MainKt" } }`. Packaging comes in M3-04, not here.
- `desktopApp/.gitignore` = `/build`.

## Part B — code (`desktopApp/src/main/kotlin/com/yogeshpaliyal/deepr/desktop/`)
1. `AppDirs.kt`: `fun appDataDir(): java.io.File` per DECISIONS D5: Windows `%APPDATA%/Deepr`, macOS `~/Library/Application Support/Deepr`, Linux `$XDG_DATA_HOME/deepr` (fallback `~/.local/share/deepr`). Create it if missing.
2. `DesktopModule.kt`: `fun desktopModule(dataDir: java.io.File) = module { … }` providing:
   - `SqlDriver`: `JdbcSqliteDriver("jdbc:sqlite:${File(dataDir, "deepr.db").absolutePath}", Properties().apply { put("foreign_keys", "true") }, DeeprDB.Schema)`. This SQLDelight 2.1 constructor creates or migrates the schema via `user_version`; check the exact signature in the jar.
   - `PreferenceRepository`: `AppPreferenceDataStore(PreferenceDataStoreFactory.createWithPath(produceFile = { File(dataDir, "app_data_store.preferences_pb").absolutePath.toPath() }))` (okio `toPath`).
   - `LinkRepository`: `LinkRepositoryImpl(get())` (no backup hook on desktop).
   - `ExportRepository`, `ImportRepository`, `SyncRepository`: tiny desktop classes whose suspend methods return `RequestResult.Error("Not supported on desktop yet")`; `getAvailableImporters()` returns `emptyList()`.
   - `AutoBackupRunner`: no-op `doWork()`. `AnalyticsManager`: no-op.
   - Nothing for ReviewManager / LocalServer* (Android-only, not requested by shared code; verify with the test below).
3. `Main.kt`: `fun main() = application { … }`: start Koin once with `sharedModule` + `desktopModule(appDataDir())`, then `Window(onCloseRequest = ::exitApplication, title = "Deepr") { DeeprTheme { DeeprApp(sharedText = null, resetSharedText = {}, clipboardLink = null, resetClipboardLink = {}) } }`. Check `DeeprTheme`'s parameters and use its defaults.

## Part C — verification you can run here
- `./gradlew :desktopApp:compileKotlin -q`.
- `desktopApp/src/test/kotlin/com/yogeshpaliyal/deepr/desktop/DesktopModuleTest.kt`: with a temp dir, start Koin (`sharedModule` + `desktopModule(tmp)`), resolve `DeeprQueries`, `PreferenceRepository`, `LinkRepository`, and **construct `AccountViewModel` through Koin** (proves its whole graph is satisfied on desktop). Insert a profile via queries and read it back. Stop Koin after. Run `./gradlew :desktopApp:test -q`.
- Don't try to open a window here (headless aarch64; the UI smoke test is M3-03 in CI).
