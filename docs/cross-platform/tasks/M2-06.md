# M2-06 — Data layer → `:shared`

## Goal
Move the link repository and link-metadata fetching into `:shared` so every platform uses the same data code. Android behaviour must be **identical**: same queries, same backup scheduling after writes, same HTTP engine (CIO), same HTML parsing (jsoup).

## Moves (`app/src/main/java/com/yogeshpaliyal/deepr/` → `shared/src/<sourceSet>/kotlin/com/yogeshpaliyal/deepr/`, **same packages**)
| What | To source set | Change |
|---|---|---|
| `data/LinkRepository.kt` (interface) | commonMain | none |
| `data/LinkRepositoryImpl.kt` | commonMain | Replace the `context: Context` constructor parameter with `private val onDataChanged: () -> Unit = {}`, so the constructor becomes `LinkRepositoryImpl(deeprQueries: DeeprQueries, onDataChanged: () -> Unit = {})`. `scheduleAutoBackup()` calls `onDataChanged()` instead of `GoogleDriveAutoBackupWorker.scheduleBackup(context)`. Everything else verbatim. `Dispatchers.IO` needs `import kotlinx.coroutines.IO` in common code. |
| `data/NetworkRepository.kt` | commonMain | The default `httpClient: HttpClient = HttpClient(CIO)` becomes `= defaultHttpClient()`, with `internal expect fun defaultHttpClient(): HttpClient` in commonMain. |
| `data/HtmlParser.kt` (class `HtmlParser` + `data class LinkInfo`) | `LinkInfo` → commonMain; `HtmlParser` → `expect class HtmlParser() { fun getTitleAndImageFromHtml(html: String, url: String): LinkInfo }` in commonMain (match the existing method signature exactly) | **actual in `shared/src/jvmShared/kotlin/...`** (shared by Android + JVM): today's jsoup code, verbatim. **actual in `shared/src/iosMain/...`**: a small regex-based parser for the same fields (`og:title`, `<title>`, `og:image`, and whatever else today's code reads, with the same fallbacks), so iOS gets equivalent results. |
| `normalizeLink(link: String): String` from `util/Utils.kt` | commonMain, new file `util/Links.kt`, package `com.yogeshpaliyal.deepr.util` | Move only this function (it's pure). Remove it from Utils.kt; Utils.kt's other functions stay in `:app`. Same package, so callers (MainActivity, SilentSaveActivity, AddLinkScreen, Home, Utils.kt, app tests) don't change. |
| `defaultHttpClient()` actuals | jvmShared: `HttpClient(CIO)`; iosMain: `HttpClient(Darwin)` | |

Expect/actual **classes** need the compiler flag: in `shared/build.gradle.kts` → `kotlin { compilerOptions { freeCompilerArgs.add("-Xexpect-actual-classes") } }`.

## Build changes (`shared/build.gradle.kts` + `gradle/libs.versions.toml` only)

- jvmSharedMain: `implementation(libs.ktor.client.cio)`, `implementation(libs.jsoup)`
- iosMain: `implementation(libs.ktor.client.darwin)`. Add the catalog entry `ktor-client-darwin = { module = "io.ktor:ktor-client-darwin", version.ref = "ktorClient" }` (3.2.3 exists on Maven Central; checked).
