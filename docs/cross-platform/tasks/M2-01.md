# M2-01 — `:ui` Compose Multiplatform module

## Goal
Create a new Gradle module `:ui`: a Kotlin Multiplatform library using **Compose Multiplatform**, targeting `androidTarget`, `jvm` (desktop) and `iosArm64` + `iosSimulatorArm64`, with **Compose resources** enabled. `:app` depends on it. Nothing moves into it yet except one trivial composable that proves the setup. The Android app must behave exactly as before.

## Exact versions (verified on Maven Central 2026-10-22; don't change without writing why in the Worker log)
- Compose Multiplatform Gradle plugin `org.jetbrains.compose` **1.10.3**. Its runtime libraries are 1.10.x: `org.jetbrains.compose.runtime:runtime`, `org.jetbrains.compose.foundation:foundation`, `org.jetbrains.compose.ui:ui`, `org.jetbrains.compose.components:components-resources`.
- Material 3 for CMP: `org.jetbrains.compose.material3:material3:1.10.0-alpha05`.
- Kotlin stays **2.2.20** (`org.jetbrains.kotlin.plugin.compose` is already in the catalog as `kotlin-compose`). AGP stays 8.11.1.
- Add these to `gradle/libs.versions.toml` (a `composeMultiplatform = "1.10.3"` version, a `compose-multiplatform` plugin alias, and library aliases for the four CMP libraries + material3).

## Files in scope (only these)
- `settings.gradle.kts`: `include(":ui")`
- `build.gradle.kts` (root): add `alias(libs.plugins.compose.multiplatform) apply false`
- `gradle/libs.versions.toml`
- NEW `ui/build.gradle.kts`. Model it on `shared/build.gradle.kts` (same plugin approach: `kotlin-multiplatform` + `com.android.library`; see DECISIONS.md D9) plus `org.jetbrains.compose` and `org.jetbrains.kotlin.plugin.compose`. Android `namespace = "com.yogeshpaliyal.deepr.ui"`, compileSdk 36, minSdk 24, Java 11 like `shared`. `commonMain` depends on `project(":shared")` (api) and the CMP libraries above.
  Compose resources config: `compose.resources { publicResClass = true; packageOfResClass = "com.yogeshpaliyal.deepr.ui.resources"; generateResClass = always }`.
- NEW `ui/src/commonMain/kotlin/com/yogeshpaliyal/deepr/ui/common/UiSmoke.kt`: one `@Composable fun UiSmoke()` that shows a `Text` from a string resource (`Res.string.ui_smoke`).
- NEW `ui/src/commonMain/composeResources/values/strings.xml` with `<string name="ui_smoke">Deepr</string>`.
- NEW `ui/.gitignore` containing `/build`.
- `app/build.gradle.kts`: add `implementation(project(":ui"))` next to `:shared`. **Do not** change the app's Compose BOM, material3 or other versions in this task.

CMP 1.10's Android artifacts resolve to androidx Compose 1.10.x, and Gradle picks the higher version. That's expected and is checked by CI.
