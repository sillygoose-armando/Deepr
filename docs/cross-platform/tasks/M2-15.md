# M2-15 — Common `DeeprApp()` root; `:app` becomes a thin host

GitHub issue: #9

## Goal
`MainActivity.kt` (494 lines) still contains the app's main layout in `fun Dashboard(...)`: the back stack, Scaffold, bottom navigation bar and `NavDisplay`. All of these now use only shared pieces (`Dashboard2`, `TagSelectionScreen` and `Settings` are in `:ui`). Move that layout into a **common root composable** in `:ui` that desktop (M3) and iOS (M4) will call too. `MainActivity` keeps only the Android-specific parts and calls it. **Android behaviour and look identical.**

## Part A — `ui/src/commonMain/kotlin/com/yogeshpaliyal/deepr/ui/DeeprApp.kt` (package `com.yogeshpaliyal.deepr.ui`, public)
```kotlin
@Composable
fun DeeprApp(
    sharedText: SharedLink?,
    resetSharedText: () -> Unit,
    clipboardLink: ClipboardLink?,
    resetClipboardLink: () -> Unit,
    modifier: Modifier = Modifier,
)
```
Contents, moved **verbatim** from `MainActivity.Dashboard` (~lines 247–494) except for the Android bits listed in Part B:
- `TOP_LEVEL_ROUTES` (`listOf(Dashboard2(), TagSelectionScreen, Settings)`, make it `private` in DeeprApp.kt);
- the `TopLevelBackStack` creation, `scrollBehavior`, haptics, `layoutDirection`;
- `CompositionLocalProvider(LocalSharedText …, LocalClipboardLink …, LocalNavigator provides backStack)`;
- the Scaffold with the bottom `NavigationBar`, `AnimatedVisibility` etc.;
- the `NavDisplay(... entryDecorators = listOf(rememberSaveableStateHolderNavEntryDecorator(), rememberViewModelStoreNavEntryDecorator()), entryProvider = …)` block (from the M2-09 migration).
- Labels already use the Compose-resources `stringResource(topLevelRoute.label)`.

## Part B — `MainActivity.kt` keeps (Android-only)
- Clipboard detection (`ClipboardManager` in `LaunchedEffect(clipboardLinkDetectionEnabled)`) stays in a slimmed `Dashboard`, which computes `clipboardLink` and calls `DeeprApp(sharedText, resetSharedText, clipboardLink, resetClipboardLink, modifier)`.
- All the **bridge providers** stay in `Dashboard`, wrapped around the `DeeprApp(...)` call, with the same values: `LocalAppVersion`, `LocalAppIcon`, `LocalIsProUser`, `LocalAppPackageName`, `LocalProfileThemeProvider`, `LocalPlatformLinkActions`, `LocalHomeServerBarBuilder`, `LocalHomeNoteViewDialogBuilder`, `LocalSettingsPlatform` (+ `reviewManager`/`appName` values they use).
- **Remove** `LocalDashboardRoute` (no `:ui` reader since M2-13b; check with `codegraph callers LocalDashboardRoute`) from `ui/.../Navigation.kt` and its provider in MainActivity.
- `setContent { … }` (theme selection, app lock, `AppLockScreen`) stays as is.
- Remove now-unused imports (ktlint).

## Out of scope
Deleting unused Android `strings.xml` entries (separate, later). Android-only screens (Backup/Restore/LocalNetworkServer/TransferLink/Drive) stay in `:app`; they're reached through the existing bridges and nav keys.
