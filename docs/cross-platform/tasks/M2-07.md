# M2-07 — Preferences → `:shared`

## Goal
`PreferenceRepository` and `AppPreferenceDataStore` live in `:shared` `commonMain`. **Android users keep all their saved settings**: the DataStore file must stay the same (`preferencesDataStore(name = "app_data_store")`, i.e. `files/datastore/app_data_store.preferences_pb`), and so must every key name and default.

## Build changes
- `gradle/libs.versions.toml`: add `androidx-datastore-preferences-core = { group = "androidx.datastore", name = "datastore-preferences-core", version.ref = "dataStore" }`. DataStore 1.1.x core/preferences-core are multiplatform (android, jvm, iOS).
- `shared/build.gradle.kts`: commonMain `api(libs.androidx.datastore.preferences.core)` (api because `:app` and `:ui` see `DataStore<Preferences>` in the constructor); androidMain `implementation(libs.androidx.datastore.preferences)` (for the `preferencesDataStore` delegate).
