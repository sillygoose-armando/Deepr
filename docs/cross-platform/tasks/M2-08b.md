# M2-08b — AccountViewModel → `:shared`

## Goal
Move `app/src/main/java/com/yogeshpaliyal/deepr/viewmodel/AccountViewModel.kt` to `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/viewmodel/AccountViewModel.kt` (same package), so every platform's UI uses the same state logic. Android behaviour is identical.

## The only allowed changes inside the view model (everything else verbatim)
1. `import android.net.Uri` goes away:
   - `fun exportCsvData(uri: Uri? = null)` → `uri: String? = null`; it already passes `uri?.toString()` to the repository → now just `uri`.
   - `fun importCsvData(uri: Uri)` → `uri: String` (same simplification).
   - `fun importBookmarks(uri: Uri, importer: BookmarkImporter)` → `uri: String` (same).
2. Constructor `private val autoBackupWorker: AutoBackupWorker` → `private val autoBackupWorker: AutoBackupRunner` (the interface from M2-08a; it only calls `doWork()`).
3. Remove the `reviewManager` constructor parameter and `fun requestReview(activity: android.app.Activity)`. The only caller (Settings.kt:88) calls the `ReviewManager` directly (see below).
4. `Dispatchers.IO` needs `import kotlinx.coroutines.IO` in common code. `Dispatchers.Main` (line ~284) stays as is.

- Grep for any other `importCsvData(` / `exportCsvData(` / `importBookmarks(` calls and convert them the same way.

Change `single<AutoBackupWorker> { AutoBackupWorker(androidContext(), get(), get()) }` to also bind the interface: `single { AutoBackupWorker(androidContext(), get(), get()) } binds arrayOf(AutoBackupWorker::class, AutoBackupRunner::class)` (or an equivalent Koin 4 syntax; `import org.koin.dsl.binds`). `viewModelOf(::AccountViewModel)` stays (constructor injection resolves the new parameter list). `ReviewManager` stays registered for Settings.
