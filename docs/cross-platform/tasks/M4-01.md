# M4-01 — iOS entry point in `:ui` (Koin iOS module, ComposeUIViewController, framework)

GitHub issue: #11

## Goal
Give a future Xcode app (M4-02) two Kotlin functions to call, mirroring `desktopApp` (`Main.kt` + `DesktopModule.kt`): start Koin with an iOS module, and return a `UIViewController` that renders `DeeprApp`. No Xcode project in this task. **Android and desktop behaviour identical.**

## Part A — move the "not supported" stubs to `:shared` (no duplication)
`desktopApp/src/main/kotlin/com/yogeshpaliyal/deepr/desktop/DesktopModule.kt` defines stub `ExportRepository`, `ImportRepository`, `SyncRepository`, `AutoBackupRunner`, `AnalyticsManager`. Move them verbatim into `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/di/UnsupportedFeaturesModule.kt`:
`fun unsupportedFeaturesModule(platform: String) = module { … }` with messages `"Not supported on $platform yet"` (desktop passes `"desktop"`, so its strings stay identical). `desktopModule(dataDir)` keeps only `SqlDriver`, `PreferenceRepository`, `LinkRepository`; `Main.kt` and both desktop tests load `unsupportedFeaturesModule("desktop")` next to `desktopModule(...)` (use codegraph to find every `desktopModule(` caller).

## Part B — iOS module + entry points, `ui/src/iosMain/kotlin/com/yogeshpaliyal/deepr/ui/MainViewController.kt`
- `fun iosModule(dataDir: String) = module { … }`: `SqlDriver` = `NativeSqliteDriver(DeeprDB.Schema, "deepr.db", onConfiguration = { it.copy(extendedConfig = it.extendedConfig.copy(basePath = dataDir, foreignKeyConstraints = true)) })`; `PreferenceRepository` = `AppPreferenceDataStore(PreferenceDataStoreFactory.createWithPath(produceFile = { "$dataDir/app_data_store.preferences_pb".toPath() }))`; `LinkRepository` = `LinkRepositoryImpl(get())` (same as desktop).
- `fun initKoin(dataDir: String)` → `startKoin { modules(sharedModule, iosModule(dataDir), unsupportedFeaturesModule("iOS")) }`. `dataDir` comes from Swift (App Group container in M4-02).
- `fun MainViewController(): UIViewController = ComposeUIViewController { DeeprTheme { DeeprApp(sharedText = null, resetSharedText = {}, clipboardLink = null, resetClipboardLink = {}) } }` (same call as desktop `Main.kt`).
- Dependencies: catalog `sqldelight-native-driver = { module = "app.cash.sqldelight:native-driver", version.ref = "sqldelight" }`; add it to `:ui` `iosMain` (create the `iosMain.dependencies {}` block). Also add `okio` only if `toPath` isn't already on the classpath (it is for desktop via DataStore; check).

## Part C — framework binary in `ui/build.gradle.kts`
For `iosArm64()` and `iosSimulatorArm64()`: `binaries.framework { baseName = "DeeprUI"; isStatic = true }`. Do **not** add `iosX64` (deprecated in Kotlin 2.3; the runner question is M4-02's).
