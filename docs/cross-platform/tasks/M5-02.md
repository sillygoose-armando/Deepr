# M5-02 — HTTP for P2P: Ktor CIO server + Ktor client `HttpPost`, local IP list (all platforms)

GitHub issue: #12. Builds on M5-01 (`shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/p2p/node/`: `P2pNode.handle(path, body, remoteHost)`, `HttpPost`, `HttpReply`). Spec limits: `docs/p2p-sync/PLAN.md` (body ≤ 4 MB, endpoints under `/p2p/v1`). **No protocol changes.** DECISIONS.md D7: `ktor-server-cio` 3.2.3 publishes iOS targets, so one server in `commonMain`.

## Part A — server, `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/p2p/http/P2pServer.kt`
`class P2pServer(private val node: P2pNode)` with `suspend fun start(port: Int = 0): Int` (returns the bound port; `0` = any free port) and `suspend fun stop()`; `val port: Int?` while running. Ktor `embeddedServer(CIO, host = "0.0.0.0", port)`:
- Only `POST /p2p/v1/{name}` (`pair`, `hello`, `sync`, `unshare`, `unpair`); anything else 404 with an empty body.
- Reject bodies > 4 MB with 413 **before** reading them fully: check `Content-Length` (missing or > limit ⇒ 411/413), then read at most the limit (`receiveChannel().readRemaining(limit + 1)`).
- Call `node.handle("/p2p/v1/$name", body, call.request.origin.remoteHost)` and reply `HttpReply.status` + body as `text/plain; charset=utf-8`. Never put exception text in a response.
- No other plugins (no logging of bodies: they contain envelopes).

## Part B — client, `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/p2p/http/KtorHttpPost.kt`
`class KtorHttpPost(private val client: HttpClient = defaultHttpClient()) : HttpPost` (reuse the existing per-platform `defaultHttpClient()`; find it with codegraph). POST `http://$host:$port$path` (bracket IPv6 literals: `[fe80::1]`), body as text, `HttpTimeout` per request (connect 5 s, request 30 s), `expectSuccess = false`; return `HttpReply(status.value, bodyAsText())`. Network errors propagate as exceptions (P2pNode already treats them as "host unreachable").

## Part C — local addresses for invites, `expect fun localIpv4Addresses(): List<String>` in `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/p2p/http/LocalAddresses.kt`
Non-loopback, up, IPv4 site-local addresses (Wi-Fi/Ethernet first if you can tell).
- `jvmShared` (Android + desktop): `java.net.NetworkInterface`.
- `iosMain`: `platform.posix.getifaddrs`/`freeifaddrs` + `inet_ntop` (`AF_INET`, skip `lo0`, skip interfaces without `IFF_UP`). Can't compile here: write carefully, CI verifies.
