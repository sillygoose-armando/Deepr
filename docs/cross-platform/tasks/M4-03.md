# M4-03 — iOS Share Extension (save a shared link into the DB), silent-save logic shared with Android

GitHub issue: #11

## Goal
Sharing a URL (or text containing one) to Deepr from Safari etc. saves it, exactly like Android's `SilentSaveActivity`. The save logic moves to `:shared` once and both platforms call it. **Android behaviour identical** (same messages, same order of checks).

## Part A — `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/data/SilentSaver.kt`
Move the body of `SilentSaveActivity.saveLinkSilently` (app/src/main/java/com/yogeshpaliyal/deepr/SilentSaveActivity.kt) plus its `normalizeLink`/`isValidDeeplink` check here, logic verbatim:
```kotlin
sealed interface SilentSaveResult {
    data object Saved : SilentSaveResult
    data object AlreadyExists : SilentSaveResult
    data object InvalidLink : SilentSaveResult
    data class Failed(val error: Throwable) : SilentSaveResult
}
class SilentSaver(linkRepository: LinkRepository, networkRepository: NetworkRepository, preferenceRepository: PreferenceRepository) {
    suspend fun save(sharedText: String, title: String?): SilentSaveResult
}
```
`save` = normalize → invalid ⇒ `InvalidLink`; `getSilentSaveProfileId.first()`; existing ⇒ `AlreadyExists`; metadata fetch when blank; `insertDeepr(...)` ⇒ `Saved`; any `Exception` ⇒ `Failed(e)`. Register `single { SilentSaver(get(), get(), get()) }` in `sharedModule` (`shared/.../di/SharedModule.kt`).
Android: `SilentSaveActivity` injects `SilentSaver` and maps results to the **same** toasts as today (`invalid_link_silent_save`, `link_already_exists`, `link_saved_silently`, `failed_to_save_link` + the existing `Log.e(TAG, …)` on `Failed`), keeping its `lifecycleScope.launch` and `finish()` behaviour. Remove now-unused injections/imports.
Test `shared/src/jvmTest/.../data/SilentSaverTest.kt` (in-memory `JdbcSqliteDriver` like `SharedModuleTest`): `InvalidLink` for `"not a link"`, `AlreadyExists` after inserting the same link, and `Saved` (inserted row with the profile id) if `NetworkRepository` can be given a ktor `MockEngine` client cheaply (add `ktor-client-mock` to `jvmTest`); otherwise only the first two and say so in the log.

## Part B — Kotlin entry for the extension, `ui/src/iosMain/kotlin/com/yogeshpaliyal/deepr/ui/ShareExtension.kt`
```kotlin
fun saveSharedLink(dataDir: String, text: String, title: String?, onResult: (String) -> Unit)
```
Starts Koin with `initKoin(dataDir)` only if `org.koin.mp.KoinPlatform.getKoinOrNull() == null` (the extension is its own process), then `MainScope().launch { … }` runs `SilentSaver.save` and calls `onResult` with `"saved" | "exists" | "invalid" | "failed"`. Swift maps these to text (shortcut: English only, because Compose resources aren't bundled into the extension; comment it).

## Part C — Xcode (`iosApp/project.yml` + `iosApp/DeeprShare/`)
- New target `DeeprShare`: `type: app-extension`, `platform: iOS`, `sources: [DeeprShare]`, `PRODUCT_BUNDLE_IDENTIFIER: com.yogeshpaliyal.deepr.share`, same `FRAMEWORK_SEARCH_PATHS`, `OTHER_LDFLAGS`, `ENABLE_USER_SCRIPT_SANDBOXING`, same pre-build Gradle script and same App Group entitlements file content (`DeeprShare/DeeprShare.entitlements`). `info.path: DeeprShare/Info.plist`, properties: `CFBundleDisplayName: Deepr`, `NSExtension: { NSExtensionPointIdentifier: com.apple.share-services, NSExtensionPrincipalClass: "$(PRODUCT_MODULE_NAME).ShareViewController", NSExtensionAttributes: { NSExtensionActivationRule: { NSExtensionActivationSupportsWebURLWithMaxCount: 1, NSExtensionActivationSupportsText: true } } }`.
- App target `Deepr`: `dependencies: [{ target: DeeprShare }]` (embeds the extension).
- `iosApp/DeeprShare/ShareViewController.swift`: `UIViewController`; in `viewDidLoad` take the first `NSItemProvider` from `extensionContext?.inputItems` conforming to `UTType.url`, else `UTType.plainText`; load it (`loadItem`), turn it into a string (`URL.absoluteString` or the text), title = the item's `attributedContentText?.string`; data dir exactly as `DeeprApp.swift` (App Group, fallback Application Support; extract the shared bit into nothing new: duplicate the 8 lines with a comment pointing to DeeprApp.swift); call `ShareExtensionKt.saveSharedLink(dataDir:text:title:onResult:)`; on result show a centered `UILabel` ("Link saved" / "Link already exists" / "Invalid link" / "Failed to save link") for ~1 s on the main queue, then `extensionContext?.completeRequest(returningItems: nil)`.
