# M2-02 — Strings into Compose Multiplatform resources

## Goal
Make every app string available to shared UI code as `Res.string.<name>` (package `com.yogeshpaliyal.deepr.ui.resources`), in **all 11 locales**, with identical text and formatting. This is a **copy**: `app/src/main/res/values*/strings.xml` stay as they are, because Android-only code still uses them. Duplicates are removed in M2-15.

## Source → target
| Android | Compose resources |
|---|---|
| `app/src/main/res/values/strings.xml` (261 strings) | `ui/src/commonMain/composeResources/values/strings.xml` |
| `app/src/main/res/values-<lang>/strings.xml` (de, es, et, fr, hi, it, ja, pl, ru, ur) | `ui/src/commonMain/composeResources/values-<lang>/strings.xml` |

- Keep `ui_smoke` (already in the target default file) and add all app strings after it.
- No plurals or string-arrays exist (checked), so only `<string>` elements are needed.
- Copy each `<string name=...>` element verbatim, including escapes (`\'`, `\"`, `\n`) and format args (`%s`, `%d`, `%1$s`).
- Drop attributes Compose doesn't use (`translatable="false"` strings: copy them to the default file only).
- Drop any `tools:` namespace usage.
- Prefer a small, deterministic script you write and run, e.g. Python using `xml.etree` or careful regex. Don't hand-type hundreds of strings. Don't commit the script unless it's tiny; mention it in the Worker log.

## Must verify (this is the risky part)
Compose resources handle Android escapes and format args differently from Android in some cases. Add `ui/src/jvmTest/kotlin/com/yogeshpaliyal/deepr/ui/StringResourcesTest.kt`. In `ui/build.gradle.kts` you may add `jvmTest.dependencies { implementation(kotlin("test")) }` and, if needed, `kotlinx-coroutines-core` from the catalog. The test, using `org.jetbrains.compose.resources.getString` inside `runBlocking`, must check the **default locale**:
1. `delete_link_confirmation_with_name` with arg `"x"` → `Are you sure you want to delete 'x'?` (escaped apostrophe becomes a plain `'`, and `%s` is substituted).
2. `silent_save_profile_description` → contains `'Save Silently'` (no backslash).
3. Every string from the Android default `strings.xml` exists: parse the Android file in the test (read it from the repo path, `../app/src/main/res/values/strings.xml` relative to the `ui` module dir), and for each name check that `Res.allStringResources` contains it. (`allStringResources` is a generated **extension property**: `import com.yogeshpaliyal.deepr.ui.resources.allStringResources`. It's generated into `ui/build/generated/compose/resourceGenerator/kotlin/jvmMainResourceCollectors/.../ActualResourceCollectors.kt` after the first `:ui:compileKotlinJvm`.)
If 1 or 2 fail because of how Compose handles escapes, transform the copied text in your script, e.g. turn `\'` into `'`. Write in the Worker log exactly what transformation you applied.
