# M2-05b — QRCodeDialog → `:ui` with a multiplatform QR library

GitHub issue: #2

## Goal
`com.lightspark:compose-qr-code` has no iOS build. Replace it in `QRCodeDialog` with **`io.github.alexzhirkevich:qrose:1.3.1`** (Compose Multiplatform QR; publishes android, desktop, iosArm64 and iosSimulatorArm64; checked on Maven Central) and move the dialog to `ui/src/commonMain`, same package `com.yogeshpaliyal.deepr.ui.components`. It should look the same: 268dp, white background, black **circular dots**, the app logo centred at 50% size in a white circle.

## Steps
1. Catalog: `qrose = { module = "io.github.alexzhirkevich:qrose", version = "1.3.1" }`; `ui/build.gradle.kts` commonMain `implementation(libs.qrose)`. **Don't** remove `compose-qr-code` from the catalog or from `app/build.gradle.kts` if anything else in `:app` still uses it: check with `grep -rn composeqr app/src`, and remove the app dependency only if this dialog was the last user. Log what you found.
2. Copy `app/src/main/res/drawable/app_logo.webp` → `ui/src/commonMain/composeResources/drawable/app_logo.webp` (copy; `:app` may still use it). Use `painterResource(Res.drawable.app_logo)` from `org.jetbrains.compose.resources`.
3. Move `app/src/main/java/com/yogeshpaliyal/deepr/ui/components/QRCodeDialog.kt` → `ui/src/commonMain/kotlin/com/yogeshpaliyal/deepr/ui/components/QRCodeDialog.kt`:
   - `R.string.x` → `Res.string.x` (same as M2-05);
   - `QrCodeView(data = …, colors = QrCodeColors(...), dotShape = DotShape.Circle) { logo overlay }` → qrose: `Image(painter = rememberQrCodePainter(data = deepr.link) { shapes { darkPixel = QrPixelShape.circle() }; colors { dark = QrBrush.solid(Color.Black) } }, …)` on a white background, with the existing logo overlay drawn on top in a `Box` (keep its modifiers: `fillMaxSize(0.5f)`, `clip(CircleShape)`, white background). Read qrose's API from its jar/sources under `~/.gradle` (you're allowed to read outside the repo) rather than guessing; use the names the 1.3.1 API actually has.
   - Keep the public signature `fun QrCodeDialog(deepr: GetLinksAndTags, …)` unchanged. Its only caller is `ui/screens/home/Home.kt:551` (codegraph), in `:app`, and it must compile unchanged.
