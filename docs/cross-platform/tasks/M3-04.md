# M3-04 — Desktop installers (unsigned) built by CI

GitHub issue: #10 · DECISIONS: D3 (CI gating), D4 (unsigned)

## Goal
Teammates can download a desktop build from GitHub Actions: `.deb` (Linux), `.msi` (Windows), `.dmg` (macOS). All unsigned (D4).

## Part A — `desktopApp/build.gradle.kts`
```kotlin
compose.desktop {
    application {
        mainClass = "com.yogeshpaliyal.deepr.desktop.MainKt"   // already there
        nativeDistributions {
            targetFormats(TargetFormat.Dmg, TargetFormat.Msi, TargetFormat.Deb)
            packageName = "Deepr"
            packageVersion = "1.0.28"          // = app versionName; jpackage needs MAJOR.MINOR.PATCH
            description = "Deepr link manager"
            vendor = "Deepr"
            modules("java.sql")                // sqlite-jdbc needs java.sql; run :desktopApp:suggestRuntimeModules and add what it lists
            linux { menuGroup = "Utility" }
            windows { menuGroup = "Deepr"; perUserInstall = true }
        }
    }
}
```
Run `./gradlew :desktopApp:suggestRuntimeModules` and include every module it suggests in `modules(...)`. Without them the packaged app can crash at runtime even though `run` works.

## Part B — local verification (this machine: linux aarch64, JDK 17 with jpackage)
- `./gradlew :desktopApp:createDistributable -q` must succeed (it builds the app image with the bundled runtime). List the output dir (`desktopApp/build/compose/binaries/main/app/Deepr/`) in the Worker log.
- Smoke-launch check without a display: run the packaged launcher (`…/bin/Deepr`) with `-Djava.awt.headless=true`. A `HeadlessException` from opening the window is **expected and fine**; a `ClassNotFoundException`/`NoClassDefFoundError` (missing JDK module) is **not**. Report which one you got. Use a timeout (e.g. `timeout 30`).
- Don't install system packages to build `.deb` locally; CI does that.

## Part C — CI: `.github/workflows/desktop-packages.yml`
- Triggers: `push` to `feature/kmp` with `paths` `shared/**`, `ui/**`, `desktopApp/**`, `gradle/**`, `**.gradle.kts`, the workflow file itself (D3); plus `workflow_dispatch`.
- `concurrency` like the other workflows.
- Matrix: `ubuntu-latest` (deb), `windows-latest` (msi), `macos-15-intel` (dmg). `macos-latest`/`macos-15` arm runners had no capacity (see kmp-ios.yml), so mirror its runner choice and its `cache-disabled: true` note.
- Steps: checkout; setup-java 21 (temurin); setup-gradle; `./gradlew :desktopApp:packageDistributionForCurrentOS` (on Windows use `./gradlew.bat` or `bash ./gradlew` with `shell: bash`); upload `desktopApp/build/compose/binaries/main/*/*` as artifact `deepr-desktop-${{ matrix.os }}` (retention 14 days).

## Acceptance
- Local: `./gradlew :desktopApp:compileKotlin :desktopApp:test :desktopApp:createDistributable -q` passes, plus the smoke-launch result is reported.
- CI (orchestrator): all 3 matrix jobs green and their artifacts present.
