## Part B — `shared/src/jvmShared/kotlin/com/yogeshpaliyal/deepr/p2p/iroh/IrohTransport.kt`
`class IrohTransport(private val node: P2pNode, private val secretKey: () -> ByteArray?, private val saveSecretKey: (ByteArray) -> Unit, private val scope: CoroutineScope)`:
- `ALPN = "deepr/p2p/1".encodeToByteArray()`.
- `suspend fun start()`: bind with `presetN0()` (public relays, D14) and the persisted key (first start: save `endpoint.secretKey().toBytes()` via `saveSecretKey`); launch the accept loop in `scope`. `suspend fun stop()`. `val ticket: String?` (this endpoint's `EndpointTicket` string while running; it'll go into invites in M5-09).
- Accept loop: for each incoming connection, for each `acceptBi()` stream: read the request frame, call `node.handle(path, body, remoteHost = "iroh:" + conn.remoteId())`, write the reply frame, `finish()`. One bad stream must not kill the loop; enforce the 4 MB limit (`readToEnd(4 MB + overhead)`), never echo exception text.
- `suspend fun post(ticket: String, path: String, body: String): HttpReply` — connect (cache one `Connection` per remote id, reconnect on failure), `openBi`, write the request frame, `finish`, read the reply frame. Timeouts like `KtorHttpPost` (connect 10 s — relays can be slower than LAN — request 30 s).
- Frames (UTF-8, big-endian lengths): request = `u16 pathLen ‖ path ‖ u32 bodyLen ‖ body`; reply = `u16 status ‖ u32 bodyLen ‖ body`. Put encode/decode in a small pure-Kotlin `commonMain` file (`p2p/iroh/IrohFrames.kt`) so it's unit-tested without natives.
