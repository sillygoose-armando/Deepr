# M4-04 — iOS simulator UI smoke test (XCUITest) in CI

GitHub issue: #11

## Goal
Prove the iOS app (M4-02) launches on a simulator and renders the shared Compose UI. No Kotlin changes.

## Part A — XCUITest target
- `iosApp/project.yml`: new target `DeeprUITests`, `type: bundle.ui-testing`, `platform: iOS`, `sources: [DeeprUITests]`, `dependencies: [{ target: Deepr }]`, settings `TEST_TARGET_NAME: Deepr`, `PRODUCT_BUNDLE_IDENTIFIER: com.yogeshpaliyal.deepr.uitests`, `GENERATE_INFOPLIST_FILE: YES`. Add a `schemes:` entry `Deepr` with `build.targets: { Deepr: all, DeeprUITests: [test] }` and `test.targets: [DeeprUITests]` (XcodeGen otherwise auto-generates a scheme without tests).
- `iosApp/DeeprUITests/LaunchTests.swift` (valid Swift; `import XCTest`):
  ```swift
  final class LaunchTests: XCTestCase {
      func testLaunchShowsHome() {
          let app = XCUIApplication()
          app.launch()
          // Compose Multiplatform exposes semantics to the iOS accessibility tree; "Home" is the bottom-nav label (Res.string.home).
          XCTAssertTrue(app.staticTexts["Home"].waitForExistence(timeout: 60) || app.buttons["Home"].waitForExistence(timeout: 5))
      }
  }
  ```

## Part B — CI: a separate job in `.github/workflows/kmp-ios.yml`
Keep the existing `ios` job unchanged (Intel). Add job `ios-ui-test`, `needs: ios`, `runs-on: macos-15` (arm64: our only simulator target is `iosSimulatorArm64`; Intel can't run it), `timeout-minutes: 60`, same checkout/JDK 21 temurin/setup-gradle (`cache-disabled: true`) steps, then:
```yaml
      - name: Generate Xcode project
        run: brew install xcodegen && cd iosApp && xcodegen generate
      - name: Run UI tests on the simulator
        run: |
          DEVICE=$(xcrun simctl list devices available | grep -m1 -oE 'iPhone [0-9]+[^(]*' | sed 's/ *$//')
          echo "Simulator: $DEVICE"
          xcodebuild -project iosApp/Deepr.xcodeproj -scheme Deepr -configuration Debug \
            -destination "platform=iOS Simulator,name=$DEVICE" CODE_SIGNING_ALLOWED=NO test
```
