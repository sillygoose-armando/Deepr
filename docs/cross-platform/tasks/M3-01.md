# M3-01 — Common Koin module (prepare desktop/iOS DI)

GitHub issue: #10

## Goal
Every platform needs the same dependency graph for the shared code. Today all Koin bindings live in `app/src/main/java/com/yogeshpaliyal/deepr/DeeprApplication.kt` (`val appModule = module { … }`). Move the **platform-neutral** bindings into a common module in `:shared`, and have Android load it next to its own module. **Android behaviour identical** (same instances, same scopes).

## Part A — `shared/src/commonMain/kotlin/com/yogeshpaliyal/deepr/di/SharedModule.kt` (public)
```kotlin
val sharedModule = module {
    single { DeeprDB(get()) }                       // needs a SqlDriver from the platform module
    single<DeeprQueries> { get<DeeprDB>().deeprQueries }
    single { HtmlParser() }
    single { NetworkRepository(get()) }              // same constructor call as today (HtmlParser; default HttpClient)
    viewModelOf(::AccountViewModel)
}
```
Move exactly these bindings out of `appModule` (keep their definitions identical). Use `org.koin.core.module.dsl.viewModelOf` (from `koin-core-viewmodel`, multiplatform). DeeprApplication already imports exactly this function (checked), so the binding is unchanged.

## Part B — dependencies
- Catalog: add `koin-core-viewmodel = { module = "io.insert-koin:koin-core-viewmodel" }` (BOM 4.1.1; multiplatform incl. iOS, checked).
- `shared/build.gradle.kts` commonMain: `implementation(project.dependencies.platform(libs.koin.bom))`, `api(libs.koin.core)`, `api(libs.koin.core.viewmodel)`.

## Part C — Android (`DeeprApplication.kt`)
- Remove the moved bindings from `appModule` (SqlDriver, PreferenceRepository, LinkRepository, Export/Import/Sync repos, AutoBackupWorker, HttpClient, LocalServer*, ReviewManager, AnalyticsManager **stay**).
- `startKoin { … modules(appModule) }` (DeeprApplication.kt:192) → `modules(sharedModule, appModule)`.
- Remove now-unused imports (ktlint).
